# 使用手册：第三层便携交付

交付目标是 Windows x64 本地播放器、账号和文件传输演示。完整解压 `native-player-3.0.0-win-x64.zip`，进入同名目录后双击 `launch-demo.cmd`。演示素材已随包提供，正常使用无需安装 PowerShell、CMake、Visual Studio、vcpkg 或 FFmpeg 命令行工具。需要交互式 Windows 桌面、可用音频输出以及支持 OpenGL 3.3 的显卡驱动；兼容渲染入口见下文。

包根目录包含 `native-player.exe`、独立账号服务 `native-service.exe`、固定地址媒体服务 `native-demo-http.exe`、两个 CMD 启动器、`media`、`docs`、`licenses` 和 `manifest.json`。不要直接从 ZIP 预览窗口运行程序，也不要移动单个 EXE 后期待演示素材仍可找到。

## 启动与数据位置

`launch-demo.cmd` 使用 `%~dp0` 定位自身和 `media`，先尝试将数据写入包内 `portable-data`；目录不可写时回退到 `%LOCALAPPDATA%\NativePlayer\portable-3.0.0`。缓存、账号服务记录、上传文件以及桌面设置都可能增加该目录的大小。启动器仅删除自己创建的写入探测文件。发布 ZIP 不包含这些运行数据；如果把已经使用过的解压目录交给别人，应重新从原始 ZIP 解压一份。

双击 `launch.cmd` 打开普通播放器，数据沿用 `%LOCALAPPDATA%\NativePlayer`。在 CMD 中也可直接运行：

```bat
native-player.exe --decoder ffmpeg
native-player.exe --source "C:\Videos\sample.mp4" --decoder ffmpeg
native-player.exe --decoder ffmpeg --demo-fixtures "media" --data-root "portable-data"
native-player.exe --renderer d3d11 --decoder ffmpeg
```

直接命令中的相对路径依赖当前目录；双击启动器使用包的完整路径。`--data-root` 可指定用户可写目录。账号上传仍使用经典 Win32 文件接口，完整路径过长会出现 `Cannot open upload partial` 或原子记录写入错误。建议数据根的绝对路径不超过 90 个字符，将包解压到较浅的用户可写目录；必要时使用 `--data-root "C:\np-data"` 等短目录。服务还会附加 `\server\uploads\<64位账号标识>\<64位任务标识>.json.tmp`，共 154 个字符；90 字符是保留余量的使用建议，不能宣称支持任意深度路径。默认渲染器是 OpenGL；若驱动初始化失败，使用 `--renderer d3d11`。本轮没有增加硬件解码保证；网络演示使用 FFmpeg 后端。

## 播放与画面控制

普通播放器通过“选择文件”、Ctrl+O 或拖放打开本地视频。空格暂停／继续，左右键前后跳转十秒，F11 切换全屏，Esc 退出全屏。界面还提供停止、重新播放、音量和置顶。暂停后拖动进度可以查看跳转预览，停止后清除画面。

设置页可调整旋转、缩放、亮度、灰度和反色；暂停帧也能观察效果。技术信息显示分辨率、播放状态、同步差值和丢帧数。1× 播放带音频，其他倍率使用视频时钟并静音，尚无音频变速功能。直接网络播放兼容性受 FFmpeg 和媒体源影响，不能用一个样例代表全部格式。

网络播放页选择本地 FLV 或 HLS 示例后，有三种模式：直接播放、边下边播并保存缓存、下载完成后播放。传输中心显示已下载量、速率和 HLS 分片数。“暂停”保留任务；“取消并保存进度”停止当前下载并保留已落盘区间，再次选择同一源可继续。“下载完成后播放”在文件完成前不会自动打开视频。

普通演示媒体服务由播放器创建，监听本机随机端口并随播放器关闭。关闭后再启动，示例 URL 通常变化。要演示跨进程续传，应使用下面的固定地址源，保持媒体、URL 和数据目录不变：

```bat
native-demo-http.exe "media" 18761
```

保持这个 CMD 窗口打开，在网络页输入 `http://127.0.0.1:18761/stream.flv` 或 `http://127.0.0.1:18761/hls/index.m3u8`。只关闭播放器，随后用同一启动器重开并重新选择同一 URL。媒体服务窗口按 Ctrl+C 退出。不要在恢复过程中替换素材。

## 账号、上传与重连

账号页点击“启动本地服务”后连接，注册临时演示账号，再输入密码登录。注册和登录为独立操作。传输中心选择包内 `media\stream.flv` 上传，观察进度，再暂停／继续。上传以服务端确认的落盘偏移恢复；取消上传会删除尚未完成的临时数据。上传完成的文件位于数据根下的 `server\files\<账号标识>\<任务标识>.bin`。

保持登录时停止本地服务，界面应进入重连状态；在原端口重新启动服务后，客户端尝试恢复会话。主动点击“断开”会清除本地登录状态，需要再次连接和登录。独立服务命令如下；不要与界面服务争用同一端口或数据目录：

```bat
native-service.exe --port 18760 --data "portable-data\server"
```

服务只监听回环地址。密码记录是随机盐和 PBKDF2 哈希，本地服务还会持久化会话令牌；这些运行数据属于使用者，不属于可交付包。桌面状态和诊断日志不应保存密码或令牌。账号功能用于本机演示，没有公网生产账号治理、TLS 或令牌过期机制。

## 设置、历史与问题处理

第三层增加 `desktop-state.json` 与有上限的 `desktop.log`，保存最近文件、画面／音量设置及下载历史。重开播放器后，最近页和设置恢复保存内容。最近记录在加载和保存时跳过含 userinfo（认证信息）、查询参数或片段的网络 URL，包括签名地址；不会将删改后的地址作为可点击的最近项，以免打开错误的源。

传输中心展开“下载历史与恢复”，可继续不需要重新输入源的任务。下载历史保留记录，但在读取和保存时去除 URL 的 userinfo、查询和片段；地址被修改或原来已标记的记录保留 `requiresSource=true`。这会禁用恢复按钮，并提示在网络页重新输入完整地址；有合法 `taskKey` 的记录仍可清理缓存。`taskKey` 是原始完整 URL 的 SHA256，仅作为经过验证的任务目录标识，不保存凭据。旧脱敏记录若缺少该标识，则无法安全定位原缓存，清理也禁用。

传输中心提供“打开缓存目录”和“打开诊断目录”。后者打开当前数据根，可以查看状态文件及诊断日志。历史项的“清理缓存”打开统一的单一确认弹窗，显示所选地址，并明确提示将停止当前播放与下载、删除所选任务缓存。点击“删除缓存”后，会先停止本应用当前的播放和下载，即使当前任务与所选历史项不同，再删除所选任务目录；点击“保留”或关闭弹窗会取消操作。目录锁拒绝其他仍在占用的实例，包括可能仍持锁的暂停／完成任务。错误原因显示在界面，清理失败不能当作成功。`desktop.log` 保持 ≤1 MiB，日志写入失败也有可见诊断。

| 现象 | 操作 |
| --- | --- |
| 无法创建数据目录 | 将包解压到用户可写目录，或用 `--data-root` 指向可写目录；查看界面错误 |
| 图形初始化失败 | 更新显卡驱动，或用 `--renderer d3d11` 启动 |
| 没有声音 | 检查 Windows 输出设备、播放器音量和倍率是否为 1× |
| 缓存源缺少可靠校验标识 | 选择直接播放；缓存需要 Range 与强 ETag 或 Last-Modified |
| 服务无法启动 | 检查端口是否被占用、目录是否被另一个本地服务独占，以及目录写权限 |
| 断点恢复没有命中 | 核对同一 URL、数据根和原始素材；随机端口或素材变化会改变任务身份 |
| 配置损坏或历史无法恢复 | 查看可见诊断；状态加载返回默认值，重新设置并使用合法源 |

优先使用上述确认式缓存清理入口。删除成功后按所选 `taskKey` 移除对应历史项；两个签名地址即使显示为同一脱敏地址，也保留未选任务。没有任务键的旧普通记录使用完整源地址定位。另一实例占用、目录链接或路径越界应拒绝；需要重新输入地址的历史仍可凭合法 `taskKey` 清理。设置加载诊断独立保留，后续保存成功不会将它清除；可点击“知道了”确认该提示。手动删除数据前先关闭本应用和自己启动的服务，并确认目录确实属于本次演示。
