# 五至八分钟固定演示

建议用六分半钟演示五项核心功能，并预留约一分钟处理输入和窗口切换。演示只使用随包合成素材和本机服务，避免依赖公网。以下是操作流程和应观察的现象，不是已执行的第三层测试结果；实际验收需记录对应版本、退出码、JSON 和截图。

演示前完整解压原始 ZIP，确认音频设备、显卡驱动和包目录可写，先阅读 [使用手册](user-guide.md)。使用新解压目录，准备仅用于本次演示的临时账号和密码，上传选择 `media\stream.flv`。FLV 为 320×180、25 fps、12 秒合成图案和测试音频；HLS 为八个 TS 分片的静音点播。不要使用真实个人文件或现有个人账号。

| 时间 | 操作 | 展示重点 |
| --- | --- | --- |
| 0:00–0:45 | 双击 `launch-demo.cmd`，网络页选择本地 FLV，“边下边播并保存缓存”，开始播放 | 无开发工具的启动；首帧出现时下载尚未完成；传输中心有下载量和速率 |
| 0:45–1:35 | 传输中心暂停下载，等待缓存耗尽；继续下载。再“取消并保存进度”，重新开始同一地址 | 暂停、缓冲和恢复；取消下载保留已落盘数据。若素材已下载完成，使用新解压目录重做这一段 |
| 1:35–2:20 | 暂停播放，设置页切换旋转、灰度／反色、亮度，回播放器跳转预览；恢复为原始设置 | GPU 画面处理在暂停帧也生效；预览、音画同步信息和播放器控制 |
| 2:20–3:20 | 账号页启动本地服务，注册临时账号，再登录；尝试一次错误密码后正确登录 | 账号业务错误和连接错误分开；本地服务和会话 |
| 3:20–4:20 | 传输中心选择 `media\stream.flv` 上传，观察非零进度，暂停后继续至完成 | 分块传输、进度和已确认偏移；展示完成文件位置，不打开其他账号目录 |
| 4:20–5:10 | 保持登录，停止本地服务，观察重连，原端口重启服务，等待会话恢复 | 心跳／重连与会话恢复；主动断开语义不同于意外断线 |
| 5:10–6:15 | 网络页选择本地 HLS，“下载完成后播放”；观察八分片完成前未自动播放，完成后打开视频 | HLS 分片缓存和完整下载模式；说明 HLS 示例静音 |
| 6:15–7:15 | 关闭后用同一演示启动器重开，展示保存的设置、本地／不含访问参数的最近项和下载历史；打开诊断目录，展示单一清理确认弹窗并选择“保留” | 最近记录跳过含认证、查询或片段的网络 URL；下载历史的 `requiresSource` 只禁用恢复，合法 `taskKey` 仍可清理；弹窗说明将停止当前播放与下载 |

固定源跨窗口续传作为备用演示，约需额外一分钟，不强行塞入主流程：在包目录 CMD 执行 `native-demo-http.exe "media" 18761`，播放器输入 `http://127.0.0.1:18761/stream.flv` 并开始缓存，取消保存或关闭播放器，保持源窗口运行，再用同一数据目录重新打开相同 URL。记录恢复前后已下载量。播放器自己的随机端口示例不能证明跨进程同地址恢复。

## 自动流程与证据

`verify-release.ps1` 会顺序启动暂存包与 ZIP 解压包各一轮 `--smoke-test` 和 `--second-layer-smoke`。五阶段覆盖 playing、paused、seek-preview、idle 和 error；十五阶段覆盖网络页、FLV 首帧、下载暂停／取消／恢复、账号注册登录、上传暂停／完成、服务重启／会话恢复、HLS 完整下载再播放。脚本等待各进程退出，再读取应用自身的 `result.json`，检查阶段数、八分片、认证和实际文件字节数，并核对截图 PNG。

自动流程会打开窗口、生成测试账号与缓存，但仅写入独立验证目录，不进入发布 ZIP。它没有替代人工确认的双击启动器操作、布局检查和故障解释，也没有替代稳定性长测或性能基准。原始日志、JSON 和截图应保留供复查。

## 演示中诚实说明的边界

- 缓存范围为可靠 Range HTTP FLV 和有限、未加密、单音轨 MPEG-TS HLS 点播；直播缓存、DRM、加密 HLS、fMP4 和多音轨不在范围。
- 非 1× 播放静音，没有音频变速；MF 后端不保证硬件解码；没有 HDR 色调映射。
- 账号服务在本机回环 TCP 演示，没有 TLS、令牌过期或公网部署治理。
- 合成媒体、第二层 smoke 和本机隔离运行不能代表全部媒体兼容性或干净 Windows 虚拟机验收。性能和长测只引用实际完成的对应证据。
- 论文、PPT、启动器页面集成和新增硬解不属于用户批准的第三层 A/A 范围。

演示结束关闭播放器及自己启动的独立服务。不要用任务管理器批量终止其他播放器或服务进程。需要将作品交给别人时使用原始 ZIP，运行数据和自动测试目录留在本机。

清理的实际删除可作为备用步骤：仅选择本次演示创建、不再使用的历史任务，阅读统一确认弹窗中的所选地址及“将停止当前播放与下载”提示，确认“删除缓存”。即使正在播放／下载其他源，也会先停止本应用当前播放和下载，再删除所选任务目录；观察停止状态与实际清理结果。若两条签名历史显示为同一脱敏地址，删除按所选任务键定位，未选历史应保留。若另一实例仍持有任务锁，应展示拒绝原因。

隐私说明可结合历史展示：签名／认证地址及任何含查询或片段的网络 URL 在最近记录加载和保存时被跳过，避免点击删改后的错误源；下载历史保留脱敏地址和 `requiresSource`，恢复按钮禁用，需在网络页重新输入完整地址。合法 `taskKey` 允许确认后清理原缓存；旧脱敏记录缺少任务键时清理也禁用。若展示加载错误，说明该诊断独立保留到点击“知道了”，不会因后续保存成功而消失。不要将按钮可用或禁用解释为清理已通过。
