# 第二层固定演示

在仓库根目录运行 `scripts/run-second-layer-demo.ps1 -Build`。首次构建需要已安装的 vcpkg 静态依赖。后续可省略 `-Build`。默认使用 Release；`-Configuration Debug` 可启动 Debug。

1. **边下边播**：网络页点击本地 FLV 示例，选择“边下边播并保存缓存”，开始播放。首帧出现时文件仍在下载。进入传输中心查看下载量和速度；暂停下载，等待播放耗尽缓存，界面进入缓冲；继续下载，播放器恢复。
2. **下载恢复**：下载中点击“取消并保存进度”；播放停止，下载记录保留。点击恢复此下载，读取已落盘进度后继续。也可关闭窗口后重新运行相同固定地址的媒体服务，再输入原地址恢复。
3. **HLS**：网络页切换本地 HLS 示例，重复播放和下载步骤。传输中心显示八个分片的完成数，取消时保存每个分片内部偏移。HLS 测试素材为静音，FLV 示例含音频。
4. **完整下载后播放**：网络页选择“下载完成后播放”，观察完成之前不自动打开视频，完成后切换播放器。
5. **渲染**：暂停视频，在设置页切换旋转、缩放、灰度、反色和亮度，返回播放器查看静态帧也会更新。打开播放技术信息查看同步差值和丢帧数。
6. **账号**：账号页启动本地服务，自动连接。注册一个账号，重新输入密码登录；错误密码显示业务错误。密码持久化记录只包含盐和 PBKDF2 哈希。
7. **上传**：传输中心选择 `build/demo-fixtures/stream.flv`。观察进度，暂停再继续；完成后提示文件已保存。服务端文件位于演示数据目录下 `server/files/<账号标识>/<任务标识>.bin`。
8. **重连**：保持登录状态，停止本地服务，观察“正在重连”；重新启动本地服务，自动恢复连接和会话。主动点击“断开”则需要再次连接与登录。

普通演示源使用进程退出时关闭的随机端口。跨窗口重新启动后地址会变化，不能用它证明相同 URL 的跨进程续传。需要固定地址时，先生成素材，再独立运行：

```powershell
& .\build\desktop\Release\make-stream-media.exe .\build\demo-fixtures
& .\bin\desktop\Release\native-demo-http.exe .\build\demo-fixtures 18761
```

播放器中使用 `http://127.0.0.1:18761/stream.flv` 或 `http://127.0.0.1:18761/hls/index.m3u8`。关闭播放器后保持源服务和文件不变，再重新打开相同地址。不要在恢复期间重新生成素材，文件校验标识变化会使缓存失效。

强制退出下载的定量验证由 `cache-playback` 测试完成：它启动并持有具体子进程句柄，确认已落盘和未落盘数据并存，再终止该子进程。重启后对比 HTTP Range 日志，检查恢复偏移、重下载量和最终字节一致性。不要通过任务管理器终止其他播放器进程来替代该测试。

自动桌面流程：

```powershell
ctest --test-dir build/desktop -C Release -R second-layer-desktop --output-on-failure
```

截图与结果位于 `build/desktop/second-layer-artifacts/Release`。该流程使用单独测试账号与数据目录，覆盖网络页、边下边播、下载暂停／取消／恢复、登录、上传暂停／完成、服务重启／会话恢复，以及八分片 HLS 完整下载后自动播放，共十五个阶段。
