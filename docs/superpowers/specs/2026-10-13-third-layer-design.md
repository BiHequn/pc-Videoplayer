# 第三层毕业设计交付设计

用户选择范围 A、文档 A，并要求尽快完成。沿用 Windows x64 / C++17 / Win32 / Dear ImGui，交付现有五项核心功能的可重复演示、稳定性证据、性能数据、便携 Release 包和项目交付文档。新增硬解与启动器页面集成、论文和 PPT 不属于本轮。

## 持久化与诊断

新增 app/desktop-state.{h,cpp}，以独立 JSON 文件原子保存设置、最近文件和下载历史，不保存密码或登录令牌。数据目录沿用 --data-root 与 LOCALAPPDATA。持久化字段进行类型、范围、数量验证，损坏文件返回默认值和可见诊断。桌面 UI 在现有页面增加恢复历史任务、打开缓存目录与安全清理入口；清理仅处理指定任务目录并先停止本应用活动缓存，目录外路径拒绝。

诊断日志写入指定数据目录，记录播放、缓存、连接和上传的状态变化及错误，不记录明文密码、token 或完整带查询参数的 URL。日志有大小上限。错误提示保留实际原因，目录不可写不使 UI 崩溃。

## 稳定性与性能

在真实 PlaybackSession 上执行至少 100 次操作循环和 60 分钟连续循环播放，记录过程 CPU、内存、句柄、线程、帧和状态；测试记录开始/结束实际墙钟时间，不把计划时长当作结果。媒体核心在长测期间不修改；必要修复后重新验证受影响部分。短 smoke 可进入普通 CTest；60 分钟测试为显式命令。

新增真实故障场景：缓存根不可写（拒绝访问 ACL 或路径阻塞的可重复模拟）、账号服务目录冲突、损坏媒体恢复、下载源断连与继续。磁盘已满若无法安全构造，则明确记录未验证，不填入已通过列表。

生成 720p、1080p、4K 固定视频，以同一 FFmpeg 解码和 OpenGL 渲染比较 native YUV 与 CPU BGRA 转换路径，记录 CPU、内存、首帧、帧率、丢帧与同步差值。生成原始 JSON/CSV 及 SVG/HTML 图表，说明合成素材、分辨率、编码、设备、重复次数和测量边界；结论以实测为准。

## 发布与文档

版本化 ZIP 包包含 native-player、native-service、native-demo-http、演示素材、双击启动入口、使用/架构/验证/演示文档和第三方许可证；不包括账号、token、个人文件或测试数据目录。包从固定发布输入复制到独立目录，并在 PATH 不含开发工具、cwd 不在源码目录的环境运行 smoke 和演示流程。只能确认本机隔离目录运行；另一台电脑或干净 Windows 虚拟机没有可用环境时列为外部验收待办。

交付文档为仓库 Markdown、原始数据与图表，覆盖使用手册、架构和线程/队列、音画同步、协议、断点恢复、测试矩阵、性能、固定答辩流程和功能边界。程序内不展示内部实现细节，技术材料单独提供。

## 工作方式

新分支 codex/third-layer-delivery，复用当前安装好的静态依赖和已验证 build，避免重复下载。各子任务使用不重叠文件范围并行；父任务负责 UI、CMake/VS、长测、故障测试和最终整体验证。用户已批准范围与执行，常规实现选择不再次索取批准。
