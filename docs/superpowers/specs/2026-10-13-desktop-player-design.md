# 第一层桌面播放器设计

用户已选择 B：不限一小时，完整完成主界面、本地播放、控制栏、状态和错误显示。

## 范围

- Windows x64、C++17、Win32、Dear ImGui、D3D11。默认启动桌面窗口，`--pip` 保留原有画中画入口。
- 中文深色界面，媒体导航、中央视频、底部控制栏。打开文件、拖放文件、暂停/继续、停止、重播、时间跳转、音量、亮度、解码选择和状态信息。
- 打开和解码在播放工作线程运行。UI 不访问 FFmpeg 全局对象；通过命令队列与受互斥保护的快照和帧通信。
- 打开失败、首帧失败、运行时失败及正常结束在界面明确区分，窗口保持可用并允许重新打开。
- Auto 保留 MF 初始化/首帧失败到 FFmpeg 的回退。首版不增加 OpenGL、账号、服务端或上传。
- 保留用户已有项目修改；实现完成后，用户于 2026-10-13 授权提交并推送本轮工作。

## 模块

`app/playback-session.*` 管理后台播放状态和帧发布；`app/desktop-player.*` 管理 Win32 窗口和 ImGui 交互；`render/desktop-renderer.*` 管理桌面 D3D11 与 ImGui 后端；原有 media 接口补充时长、绝对跳转、音量、取消和后端信息。

Release/Debug 构建；真实媒体集成测试覆盖打开、暂停、跳转、结束、无音频时钟、错误后重新打开和关闭；实际窗口截图检查空状态、播放、控制与错误页面。说明操作、构建及限制。
