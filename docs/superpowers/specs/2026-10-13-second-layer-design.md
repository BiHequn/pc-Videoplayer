# 第二层完整功能与边下边播设计

用户已批准按方案执行。目标为 Windows x64 / C++17 / Win32 / Dear ImGui 的本地毕业设计演示，沿用第一层操作与 PiP。

## 服务与上传

独立 native-service 进程监听 127.0.0.1:18760，可配置端口与数据目录。TCP 消息使用 4 字节网络序长度 + UTF-8 JSON，最大 2MB；version=1、id、op、body，请求和响应一一对应。响应含 ok、code、body。客户端后台维持连接，2秒心跳、5秒响应超时、1/2/4秒重连；请求重试保留 id，上传以服务端确认的 offset 为准。

账号持久化为原子替换 JSON，密码 PBKDF2-HMAC-SHA256、独立随机盐、600000迭代，不保存明文。会话使用随机 token。注册、登录、登出、会话恢复、心跳及异常响应均有真实 TCP 测试。服务仅用于本机演示，不自动开启公网监听。

上传以256KiB分块，初始化以文件 SHA256+大小生成用户隔离任务，服务端校验 offset 和块 SHA256、刷盘后确认，暂停或进程退出后可查已确认 offset。完成校验完整 SHA256，再发布文件。重复块幂等；文件名不得改变服务器存储根路径。

## OpenGL 与视频帧

桌面窗口支持 OpenGL 3.3 渲染；WGL 上下文、ImGui OpenGL 后端、YUV420P 三纹理和着色器 YUV→RGB、VBO/VAO/FBO。软件解码输出原始 YUV420P，避免先在 CPU 转 RGB；MF 帧保持 BGRA 兼容。D3D11/PiP 仍使用原输出。增加旋转0/90/180/270、缩放和灰度/反色/亮度。精确 seek、帧复制和生命周期保持第一层规则。

DecodedVideoFrame / QueuedVideoFrame / PlaybackFrame 增加格式与三平面。普通 BGRA 仍默认；桌面 OpenGL 打开前要求软件解码 nativeYuv。帧的像素存储在发布后不可变。

## 网络与缓存

网络页支持直接网络播放、边下边播、全部下载后播放。RTMP 使用直接 FFmpeg 网络读取；HTTP FLV / HLS VOD 使用缓存链路。下载与播放进度分开显示。

缓存任务提供带 Range 的本机 HTTP 读取端点。播放器 FFmpeg 读取本机缓存服务；缺少的字节/分片阻塞等待而非报告EOF，支持取消和30秒无下载进展的重试窗口。HLS 提前生成完整本地端点播放列表，后台并发下载分片；请求未缓存分片会提升优先级。FLV 使用连续已完成字节区间，优先处理播放读取位置附近分块；跳转通过 Range 请求提升对应下载优先级。播放器不读取预分配文件的未完成洞。

每任务最多4下载线程；64KiB网络块、512KiB持久化检查点。checkpoint 先 FlushFileBuffers 再原子替换元数据，任务恢复最多重复小于1MiB/线程；取消时落盘。HLS 分片也保存单片partial offset；源必须提供强 ETag 或 Last-Modified；标识或长度变化使旧进度失效。首批可读内容后播放，无需等待全部下载。缓存断线继续使用已缓存内容；耗尽时暂停音画，显示缓冲并在恢复后继续。

## 界面与验收

新增网络播放、账号与连接、上传/下载传输中心；显示进度、速度、缓存范围、错误、暂停继续取消。界面以后台 LocalServer 实例启动本机服务，关闭窗口时停止所拥有的实例；另提供独立 native-service 进程供手动演示。

验收包含原第一层测试、真实TCP账号/上传/重连、实际OpenGL图像校验、限速HTTP FLV与HLS首帧早于下载完成、缓存EOF等待与取消、强制退出恢复字节量检查。生成固定测试素材和本机服务脚本。Release/Debug与文档验证后交付；无音频变速、DRM、直播缓存、HLS加密/多音轨矩阵和公网生产部署不在此轮。
